# Proposal

## Why

Enable employers and citizens to verify certificate authenticity via public QR scans without leaking candidate Aadhaar or sensitive PII.

## What Changes

Implements production functionality for Zero-Authentication Public QR Certificate Verification.

## Capabilities

### New Capabilities
- `public-verification`: Zero-Authentication Public QR Certificate Verification

### Modified Capabilities
None.

## Impact
Full integration across backend API runtime, database entities, background workers, and responsive frontend UI.
