# Proposal

## Why

Enable Training Centres to register training batches and ingest candidate rosters via streaming ExcelJS parsing with row-level validation and formula injection sanitization.

## What Changes

Implements production functionality for Training Centre Batch Ingestion & Streaming Validation.

## Capabilities

### New Capabilities
- `batch-management`: Training Centre Batch Ingestion & Streaming Validation

### Modified Capabilities
None.

## Impact
Full integration across backend API runtime, database entities, background workers, and responsive frontend UI.
