# Proposal

## Why

Generate tamper-evident, landscape A4 PDF certificates with embedded cryptographically signed QR codes via background BullMQ workers.

## What Changes

Implements production functionality for Asynchronous PDFKit & QR Certificate Rendering.

## Capabilities

### New Capabilities
- `certificate-issuance`: Asynchronous PDFKit & QR Certificate Rendering

### Modified Capabilities
None.

## Impact
Full integration across backend API runtime, database entities, background workers, and responsive frontend UI.
