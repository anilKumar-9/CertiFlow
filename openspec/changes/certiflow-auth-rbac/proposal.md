# Proposal

## Why

Secure the CertiFlow platform using asynchronous bcrypt hashing, dual-token JWT lifecycle, refresh token rotation with reuse detection, and district-scoped RBAC authorization.

## What Changes

Implements production functionality for Authentication & Role-Based Access Control.

## Capabilities

### New Capabilities
- `auth-rbac`: Authentication & Role-Based Access Control

### Modified Capabilities
None.

## Impact
Full integration across backend API runtime, database entities, background workers, and responsive frontend UI.
